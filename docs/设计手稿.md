# 设计手稿

## 大纲
1. 先暂定3个主页面， 首页/运动总结/运动目标
2. 默认显示主页， 顶部切换菜单，导航栏左右分布， 左侧为默认图标点击跳转首页，右侧为具体菜单项，及相关快捷功能（浅色/深色模式切换，语言切换，小米登录入口（用于获取useId与 passToken,默认使用（https://account.xiaomi.com/fe/service/login/qrcode?_locale=zh_CN）））
3. 页面主要使用vue3+TS及其生态（所有技术或依赖 优先使用最新发行版）

## 首页布局
1. 上部用于显示当日的信息，如每日活动汇总、睡眠情况、当日心率情况 静息心率如何
2. 下部分 显示近期运动记录，点击相关记录行的详情按钮，使用子页面或弹窗 显示 轨迹，心率，步幅，步频等等详情数据。

## 运动总结
1. 默认 按照月份显示每月的运动情况，可切换年，周，天维度
